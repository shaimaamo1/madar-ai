# Original photorealistic synthetic demo images

All 30 WebP images are original outputs created for MADAR AI using the available OpenAI image-generation tool. They are not downloaded real-estate listing photographs, stock photographs, or photographs of verified properties. No third-party listing images or branded reference photographs were supplied to generation.

Usage of these generated outputs is subject to applicable law and the OpenAI terms governing generated output (https://openai.com/policies/terms-of-use/). This file does not claim a third-party photographer's license or that a fictional listing represents a real photographed property.

Every asset is **AI-generated and illustrative**. Keep the application’s DEMO / FICTIONAL and AI-generated illustrative-image labels when presenting the listings. Property locations, prices, specifications and availability are fictional; imagery is not evidence that those facts were verified.

`manifest.json` records each listing reference, property type, original scene description, dimensions, size and original/optimized SHA-256 checksums. All files are bundled locally; no image hotlinks or external services are required to display them. Originals are encoded as optimized WebP without embedded personal/location metadata. The former repeated SVG cartoons have been removed.
